# Инструкция для носителя казахского языка

Цель: проверить предложенные правки, чтобы они попали в оценку качества. По правилам кейса строки без отметки человека не оцениваются, а жюри смотрит 150 случайных изменённых строк. В финальный `intl_kk_fixed.arb` (`scripts/run_pipeline.sh apply`) попадают **только проверенные** строки, поэтому чем больше строк проверено (минимум ~150), тем лучше. Черновик со всеми предложениями (`x-reviewed: false`) только для просмотра.

## Что открыть

`out/review_kk.csv` (UTF-8, нормально открывается в Excel и Google Sheets). Одна строка на ключ, сначала самые серьёзные.

| Колонка | Что там |
|---|---|
| `source` | русский оригинал |
| `target` | текущий казахский текст |
| `suggestion` | предложенная правка (LLM или правило инструмента) |
| `evidence` | почему строку пометили |
| `comment` | пояснение к предложению |

## Что заполнить

| `decision` | Когда ставить | `final_text` |
|---|---|---|
| `accept` | предложение верное | пусто |
| `edit` | нужен свой вариант | ваш текст |
| `keep` | текущий перевод верный, находка ложная | пусто |
| `skip` / пусто | не смотрели | — |

В колонке **`reviewer` обязательно укажите имя**: без него строка считается непроверенной.

Правила для `final_text`:
- плейсхолдеры `{name}`, `{count}` и т. п. переносите без изменений: `apply` отклонит текст с другим набором;
- не ставьте аффикс сразу после плейсхолдера (`{name}-ға`): переформулируйте («{name} ойыншысына») или напишите в `comment`, что нужна обработка в коде;
- сохраняйте `\n` (переносы строк) и теги `<g>…</g>`;
- для коротких кнопок держите длину близко к русской.

Строки с пустым `suggestion` (например «тігіс» в разделе ставок, «сезонный пропуск») ждут вашего решения по термину: впишите вариант в `final_text` с `edit` или поставьте `keep`.

## После ревью

```bash
scripts/run_pipeline.sh apply      # intl_kk_fixed.arb с x-reviewed: true, report.json, review_stats.json
```

Цифры из `out/review_stats.json` перенесите в раздел 5 `METHODOLOGY.md`: сколько строк проверено, принято, исправлено, отклонено.
